# CineBingo

Bingo interativo para avaliar momentos de um filme. Escolha um gênero, marque as casas com um X de giz e complete uma linha para formar **FILME!**

## Como usar

Abra `index.html` em um navegador. O projeto usa apenas HTML, CSS e JavaScript, sem dependências ou banco de dados. A cartela e as marcações ficam salvas no navegador com `localStorage`.

## Hospedagem

Pode ser publicado como site estático no Cloudflare Pages ou GitHub Pages. Supabase não é necessário para a versão atual.

A versão publicada no Sites está em [filme-foda-bingo.pastelcalf16.chatgpt.site](https://filme-foda-bingo.pastelcalf16.chatgpt.site) e requer acesso à conta do proprietário.
